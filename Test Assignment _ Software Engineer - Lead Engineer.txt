       Core Features (MVP)  
   1. Product & Price Comparison  
• Allow admin to add products  using a Lazada/Shopee product URL or SKU.  
• Fetch and display:  
o Product title, image, store name, price.  
o Show best price badge  between platforms.  
• Use public APIs if available, or mock adapters  (JSON fixtures or simple scraping).  
   2. Affiliate Link Generator  
• Allow admin to create a Campaign  (name, start/end, UTM parameters).  
• For each product, generate an affiliate short link  for Lazada or Shopee:  o Example: /go/abc123  redirects → marketplace URL + UTMs.  
• Track all clicks with timestamp, campaign, and referrer.  
     3. Promotion Landing Page  
• Public landing page showing campaign products:  
o Product image, price compare, Buy on Lazada/Shopee buttons.  
o Clicking CTA triggers affiliate redirect and tracks click.  
      4. Analytics Dashboard  
• Admin panel to view:  
o Click count per product, per campaign, per marketplace.  
o CTR, top-performing products.  
• (Optional bonus) Include simple charts or a leaderboard view.
